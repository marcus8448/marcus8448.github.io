I started to contribute to Galacticraft through issue/bug reports in 2017 and basic pull requests in 2018.
In 2019, I was invited to work on Galacticraft 5 (called Galacticraft: Rewoven at the time),
which I contributed to until 2026.

## Contribution highlights
* Implemented a graph-based wire network (power distribution) system
* Created an extensible framework for making machines (see [MachineLib](/projects/mods/machinelib))
  * Implemented a dynamic (runtime) model generation system for machines,
    increasing game startup speed **19x**.
* Designed extensible APIs for both developers and players to extend Galacticraft's functionality 
  * Utilized Minecraft's "datapack" system to allow players to create and load their own rockets, planets and galaxies at runtime.

## Features

* Explore the solar system in your own spaceship!
* Support for custom rocket parts and planets via datapacks
* Manage machines that use electricity
* Manage oxygen systems to sustain life in space
* Custom ores, tools, structures, items and blocks to aid your journey to the stars
